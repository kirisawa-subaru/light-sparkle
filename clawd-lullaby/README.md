# 黑猫与 Clawd 的摇篮曲

一只黑猫和 Clawd 合奏一首钢琴摇篮曲，画面是蜡笔手绘风格。整个作品是一个 HTML 文件：画面用 canvas 实时绘制，钢琴、猫叫和琴槌声都由 Web Audio 实时合成，不使用任何图片或音频素材。

灵感来自 [@kevin_t_ngo](https://x.com/kevin_t_ngo) 发布的一段 Claude Opus 5.5 作曲并用 JavaScript 绘制的钢琴动画。

## 怎么玩

用浏览器直接打开 `index.html`，不需要安装任何东西。

| 操作 | 效果 |
|---|---|
| 点画面，或按空格 | 开始 / 暂停 |
| 点右上角的台灯，或按 `L` | 开灯 / 关灯 |

## 会发生什么

- **开演前**：猫在钢琴顶上睡觉。
- **点开始**：猫醒来，转身，从琴身爬到地板上，转回来趴好，再把尾巴伸向低音区。音乐等它趴好才开始。
- **合奏**：Clawd 在琴键上逐音跳跃，弹右手旋律。落在哪个键由跳的方向决定用哪只脚。猫用尾巴尖点左手伴奏。尾巴长度固定，远的键伸直去够，近的键弓起来。
- **强弱**：谱面标有 p、mp、f 和渐强渐弱，音量和 Clawd 跳跃的力度都跟着谱走。
- **关灯**：Clawd 先吓一跳，然后眯成 `> <` 摸黑弹。猫能夜视，不受影响，眼睛在黑暗里发亮。

## 摸黑弹错的规则

只有关灯时 Clawd 才会弹错。猫的伴奏从不出错。

- **错音概率**：基础 8%，和上一个音每隔一个白键加 9%，每慌一级再加 10%，最高 90%。
- **错成什么**：通常往跳的方向冲过头一到两个半音，按错的键真的会发出那个错音。
- **慌**：弹错一次慌一级，最多三级；弹对一次降一级。慌到第三级时，下一个音必定弹对。
- **力度**：每慌一级，力度加 60%，弹对的音也一样。只有弹错的音会叠上刺耳的泛音和琴槌的"咔"声。
- **反应**：弹错后随机出现吓一跳、冒汗，或两者都有。猫有 40% 的概率喵一声，两声之间至少隔 2.5 秒。

## 录制视频

`tools/record.mjs` 用无头 Chrome 实时录一遍完整的演奏，画面和声音都在，输出 webm。需要 Node 22 以上版本，以及 Chrome 或 Chromium。

```bash
node tools/record.mjs --out take.webm --lights-off 10   # 第 10 秒关灯；-1 表示全程开灯
ffmpeg -i take.webm -vf "fps=60,fade=t=out:st=53.7:d=1" -af "afade=t=out:st=53.2:d=1.5" \
  -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart take.mp4
```

弹错和猫叫都是随机的，每次录出来都不一样。找不到 Chrome 时，用 `--chrome /path/to/chrome` 或环境变量 `CHROME` 指定路径。录好的视频不放进仓库。
